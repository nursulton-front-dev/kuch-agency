# Публикация на cPanel: kuchgroup.uz

Проект настроен для статического экспорта: после сборки готовый сайт находится
в папке `out/`. На сервер не нужно устанавливать Node.js или запускать приложение.

## 1. Собрать сайт на компьютере

Нужен Node.js 20.19 или новее. Проверить версию:

```bash
node --version
```

Затем в корне проекта:

```bash
npm ci
npm run deploy:check
```

Команда выполнит проверку кода, тесты и создаст папку `out/`.

## 2. Загрузить файлы в cPanel

1. Откройте **File Manager** в cPanel.
2. Откройте корневую папку домена `kuchgroup.uz`. Обычно это `public_html`;
   для дополнительного домена используйте его **Document Root** из раздела
   **Domains**.
3. Удалите либо переименуйте стандартный файл `index.html`, если он там есть.
4. Откройте папку `out/` на компьютере, выделите **её содержимое** (включая
   папки `_next`, `blog`, `services`, `videos` и файлы `index.html`,
   `sitemap.xml`, `rss.xml`) и упакуйте его в ZIP-архив.
5. Загрузите ZIP в корневую папку домена, нажмите правой кнопкой на архиве →
   **Extract**. Файлы должны лежать непосредственно в корневой папке домена:
   `public_html/index.html`, а не `public_html/out/index.html`.
6. Удалите ZIP после распаковки.

## 3. Подключить домен и HTTPS

1. В cPanel → **Domains** убедитесь, что `kuchgroup.uz` использует папку,
   куда были распакованы файлы.
2. Если домен зарегистрирован не у этого хостинга, укажите в его DNS
   IP-адрес сервера из письма хостинга или DNS-записи, предоставленные ahost.
3. В cPanel → **SSL/TLS Status** запустите **Run AutoSSL**. После выпуска
   сертификата включите перенаправление на HTTPS в разделе **Domains**, если
   оно доступно.

## 4. Проверить публикацию

Откройте:

- `https://kuchgroup.uz/`
- `https://kuchgroup.uz/services/`
- `https://kuchgroup.uz/sitemap.xml`
- `https://kuchgroup.uz/rss.xml`

Канонические ссылки, sitemap и RSS уже используют `https://kuchgroup.uz`.

## Обновление сайта

После изменений снова выполните:

```bash
npm run deploy:check
```

Удалите старое содержимое корневой папки домена, кроме служебных папок
хостинга, и загрузите новое содержимое `out/` тем же способом.

## Заметки

- Формы сейчас являются заглушками: отправка заявок в почту, Telegram или CRM
  ещё не подключена.
- Картинки команды, кейсов и выпусков в `public/images/...` содержат
  временные изображения KUCH и должны быть заменены реальными перед запуском.
