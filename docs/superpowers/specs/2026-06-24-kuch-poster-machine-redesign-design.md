# KUCH — «Постер-машина». Редизайн (design spec)

Дата: 2026-06-24 · Ветка: `redesign/poster-machine`
Направление: **максимально смелое («Постер-машина»)**, объём: **весь сайт**.

Это единый источник правды для редизайна. Любой агент/исполнитель сверяется с этим документом и существующими «эталонными» компонентами (Hero, About) перед сборкой своей части.

---

## 1. Цель

Сделать сайт KUCH «дерзким, современным, запоминающимся», передающим дух брендбука (`Kuch.pdf`). Сайт должен *демонстрировать* силу, а не описывать её. Палитра и шрифты из брендбука — неизменны. Контент (услуги, цены, кейсы, команда) сохраняется, копирайт обостряется под голос бренда.

## 2. Бренд (из брендбука)

- Слоган: **МЫ НЕ БОИМСЯ СЛОЖНОГО**.
- Идея: бренд, который не объясняет силу, а демонстрирует. Никакой мягкости, никаких «мы стараемся» — уверенность и конкретика.
- Три столпа: **01 Сила** · **02 Тяжёлая работа** · **03 Результат**.
- Tone of voice: **Прямо · Уверенно · Без воды · По делу**.
- Дисциплины: Маркетинг, Стратегия, Брендинг, Аналитика.

## 3. Шрифты (подтверждено по факту)

- **HeliosExt** (otf, 222 глифа, **полная кириллица А-Я/а-я + латиница**) → дисплейный (`--font-display`). Только Regular + Bold. Заголовки набираем **Bold**, аптокейс, плотный/отрицательный трекинг, гигантский кегль.
- **TT Hoves** (ttf+woff2, 1350 глифов, полная кириллица) → текстовый (`--font-sans`). Веса: 400/500/600/700/900. Black (900) — для редких постерных заливок.
- Установка: TT Hoves — копировать готовые `.woff2` в `public/fonts/`. HeliosExt — конвертировать `heliosext.otf`+`heliosext_bold.otf` → `.woff2` (fonttools venv в scratchpad). Подключение через `next/font/local` в `app/layout.tsx`; `@font-face`/токены в `app/globals.css`. **Убрать Unbounded + Golos Text.**
- Старые файлы `public/fonts/unbounded-*`, `golos-*` удалить после переключения.

## 4. Цвет = постер

Токены уже в `globals.css` (`@theme`), сохраняем имена:
`--color-kuch-black #101010` · `--color-kuch-pink #FF61E5` · `--color-kuch-pink-light #FFBEF4` · `--color-kuch-coral #FF618E` · `--color-kuch-red #FF0048` · `--color-kuch-blue #95B1FF` · `--color-kuch-white #FFFFFF`.

Принципы: секции — full-bleed «плакаты», жёстко чередуем фоны (black → pink → blue → white → black). Без градиентов. Контраст максимальный. Коралл/красный/светло-розовый — точечные акценты. На цветных фонах текст всегда `kuch-black` (контроль контраста).

## 5. Семь фирменных приёмов

1. **Плашки-цензуры (CensorBar)** — слова частично/полностью закрыты плашкой, которая на загрузке/скролле уезжает (reveal) или наезжает (redact) через `clip-path` wipe. Ключевой приём.
2. **Гигантское KUCH, режущее край (GiantType / KuchBleed)** — буквы как фоновая графика, обрезаны вьюпортом, лёгкий параллакс.
3. **Кинетические марки (KineticMarquee)** — бегущие строки, скорость/направление реагируют на скролл.
4. **Текст × фото** — крупный тип наезжает на фото (команда, кейсы), выбивка/перекрытие.
5. **Лок-ап `KUCH ×`** — круглые бейджи KUCH × Клиент (TrustedBy).
6. **Глитч-момент** — RGB-сплит / дешифровка текста. Максимум 1–2 раза за сайт.
7. **Редакторская нумерация (SectionIndex)** — `01 — Idea`, `02 — Услуги`…

## 6. Движение и доступность

- Входы: clip-wipe / маск-ревил, не просто фейд. Easing решительный (`[0.16,1,0.3,1]` / easeOut), без bounce.
- Скролл: параллакс гигантских букв, marquee velocity coupling, censor-reveal через `whileInView` (`once:true`).
- Hover: «цензура»-свайп на ссылках/кнопках; магнитный курсор-плашка (десктоп).
- **prefers-reduced-motion**: всё деградирует в мгновенное/статичное. Курсор и глитч отключаются. Использовать `useReducedMotion()`.
- Только `transform/opacity/clip-path`. `will-change` точечно. Никакого layout-thrash.
- A11y: контраст AA, `focus-visible`, слоганы-плашки дублируются `sr-only` полным текстом, marquee — `aria-hidden`.

## 7. Новые/обновлённые примитивы (`components/ui/`)

- `CensorBar` — оборачивает текст; пропсы: `as`, `color` (pink/blue/coral/white/black), `mode` ('reveal'|'redact'|'static'), `delay`, `direction`. На reduced-motion — показывает текст без плашки.
- `GiantType` — гигантская дисплейная строка/буквы, `bleed` (обрезка краем), `parallax?`, `className`, `aria-hidden`.
- `KineticMarquee` — замена/надстройка над `Marquee`: `items`, `baseSpeed`, `scrollCoupled?`, `direction`, `separator`. `aria-hidden`.
- `PosterTile` — «плакат»-карточка: `bg` (accent), `image?`, `title` (giant), `label?`, `href?`, hover-эффект (тип/фото collision). Для кейсов/команды.
- `MagneticButton` — обёртка/вариант кнопки с магнитным притяжением к курсору (десктоп, reduced-motion → обычная).
- `Cursor` — кастомный курсор-плашка (десктоп, не-touch, не reduced-motion). Монтируется один раз в layout.
- `RevealClip` — как `Reveal`, но clip-path маска вместо/вместе с translate. Универсальный вход.
- `SectionIndex` — `NN — Заголовок` лейбл секции.

Обновить: `Button` (добавить censor-hover, сохранить варианты primary/ghost/dark + API), `Section` (поддержать bg coral/pink-light, опц. номер/нумерацию, full-bleed), `Tag`/`Card` под новый стиль. `Container` оставить. `cn` оставить.

**Важно для параллельной работы:** общие файлы (`globals.css`, `layout.tsx`, `data/*`, `lib/*`, примитивы `components/ui/*`) трогает только фундаментная фаза. Агенты фан-аута редактируют **только свои** секции/страницы и не меняют общие файлы.

## 8. Структура главной (`app/page.tsx`)

Порядок секций сохраняем, переосмысляем визуал:
- **00 Header** (`components/layout/Header.tsx`) — KUCH слева, навигация, CTA-плашка. Сжатие на скролле. Моб. меню — полноэкранное с гигантскими словами + марка.
- **01 Hero** — чёрный; гигантское KUCH режет правый край (параллакс); слоган «МЫ НЕ БОИМСЯ СЛОЖНОГО» с CensorBar (плашки наезжают→уезжают, «БОИМСЯ» — розовая выбивка); eyebrow LogoCycle; подзаголовок; 2 CTA; нижняя марка. Модалка заявки сохраняется.
- **02 About / Idea** — белый постер; «НЕ ОБЪЯСНЯЕМ СИЛУ — ДЕМОНСТРИРУЕМ»; три столпа жёсткой сеткой, крупные розовые номера; ряд цифр (7+ лет / 120+ проектов / 40+ брендов / ×2.5 рост).
- **03 Ton of voice** (новая мини-секция или часть About) — magenta full-bleed; слоган с цензурой + чипы `Прямо · Уверенно · Без воды · По делу`.
- **04 Services** — чёрный; 4 дисциплины (иконки `Icon`); крупные строки-списки: hover заливает строку цветом + свайп + стрелка; ссылки на `/services/[slug]`.
- **05 Cases (VideoCases)** — текст×фото; название кейса гигантом перекрывает обложку; плитки blue/black/coral; данные `data/cases.ts`.
- **06 Team** — постерная сетка как Social media дека; имя HeliosExt + роль + фото + цветоблок; микс акцентов; данные `data/team.ts`.
- **07 Pricing** — редакторская таблица; крупные числа; hover-подсветка строк; `data/pricing.ts`, `lib/unitLabel.ts`.
- **08 TrustedBy** — марка из бейджей `KUCH × Клиент` (текстовые лок-апы; svg-файлов клиентов нет — fallback на текст). `data/clients.ts`.
- **09 BlogPreview / 10 RatingPreview / 11 TalksPreview** — редакторские карточки; данные `data/articles.ts|rating.ts|talks.ts`.
- **12 ContactCta** — финальный постер «ГОТОВЫ К СЛОЖНОМУ?» + форма/бриф.
- **13 Footer** — гигантское KUCH во всю ширину (обрезано), навигация, контакты, соцсети, слоган.
- `StickyCta` — переосмыслить под стиль (плашка), сохранить логику появления.

## 9. Внутренние страницы

Единый «постер-хедер» (SectionIndex + заголовок-гигант + цветоблок + KUCH-вылет), далее контент в редакторской сетке:
- `app/services/page.tsx`, `app/services/[slug]/page.tsx`
- `app/cases/page.tsx`, `app/cases/[slug]/page.tsx`
- `app/blog/page.tsx`, `app/blog/[slug]/page.tsx` (+ `mdx-components.tsx` стилизация)
- `app/pricing/page.tsx`, `app/rating/page.tsx`, `app/kuch-talks/page.tsx`
- `app/contact/page.tsx`, `app/brief/page.tsx` (многошаговый бриф как постер)
- Формы `components/forms/*` — стилизовать под бренд (плашки/жёсткие рамки), логику валидации/сабмита не ломать.

## 10. Копирайт

Голос: Прямо · Уверенно · Без воды · По делу. Заголовки — утверждения; CTA — императив. Факты не выдумывать (цены/кейсы/команда — как в data). Обостряем: hero-подзаголовок, заголовки секций, лейблы, интро. Слоганы-плашки обязательно дублировать `sr-only`.

## 11. Техника / критерии готовности

- Стек: Next 16 (App Router, Turbopack), React 19, Tailwind v4 (CSS-first `@theme` в globals), Framer Motion 12, MDX.
- `npm run build` — зелёный; `npm run lint` — без новых ошибок; `npm run test` — адаптировать падающие тесты под новую разметку (структура/тексты меняются осознанно), не удалять покрытие без причины.
- Dev: `localhost:3001` (3000 занят) — живое превью.
- Перф: шрифты `font-display: swap`, разумный preload дисплея; не грузить лишние веса.
- Реализм: декоративные изображения существуют в `public/images/...`; клиентских svg нет — текстовые лок-апы.

## 12. Порядок работ

1. Фундамент (solo): шрифты, токены/globals, примитивы.
2. Флагман (solo): Header, Hero, About(+Ton of voice), Footer — задаёт «лук».
3. Фан-аут (параллельно): остальные секции главной + внутренние страницы + формы, каждый по своим файлам, сверяясь с этим спеком и эталонами.
4. Копирайт-проход.
5. Верификация: build/lint/test + рендер-чек/скриншоты, фиксы.
